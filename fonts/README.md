# Fonts

Self-hosted copies of the site's three typefaces (WOFF2, split by Unicode subset as Google Fonts serves them):

- **Instrument Serif** (regular, italic): Rodrigo Fuenzalida, Jordan Egstad
- **Cabin** (600–700, variable): Impallari Type
- **IBM Plex Mono** (400, 500): IBM

All three are licensed under the [SIL Open Font License 1.1](https://openfontlicense.org), which allows
self-hosting. The `@font-face` rules live inline in `index.html`.
